# Privacy Policy — CEMÍ

## Core commitments

- **No data collection.** CEMÍ does not collect, aggregate, or transmit any telemetry, analytics, crash reports, or usage metrics. There is no "phone home" behavior.
- **Local only.** CEMÍ runs entirely on your machine. It does not require an internet connection, does not open network sockets, and does not contact any remote service.
- **No secrets are stored.** CEMÍ never persists tokens, passwords, API keys, cookies, session data, or credentials of any kind. Redaction is applied before any value is written to disk.
- **User-controlled output.** Reports generated by CEMÍ are saved to paths you choose, on your machine, and are not uploaded or shared by the tool.

## Platform limitations

CEMÍ is designed for Windows systems. On non-Windows platforms (Linux, macOS, etc.), some collectors will be skipped entirely and others may return limited or no results. The tool will display a warning when run on non-Windows systems.

## What CEMÍ scans

CEMÍ inspects **system metadata and configuration** only. In future phases this will include:

- Installed applications (names, versions, publishers)
- Startup entries and scheduled tasks (names and targets, redacted)
- Services (status and configuration)
- Browser security-relevant configuration (e.g., extension permissions metadata — **not** browsing history or cookies)
- File/registry permission posture for system locations
- Code-signing status of executables

## What CEMÍ does NOT scan

CEMÍ is explicitly forbidden by design from accessing:

- Personal documents, photos, videos, or media files
- Email content or mailboxes
- Browser history, bookmarks, cookies, saved passwords, autofill data, or form data
- Chat logs, message histories, or communication content
- Clipboard contents
- Keystrokes, mouse events, or any input telemetry
- Any user-authored content

## Redaction

All paths containing usernames are redacted to `C:\Users\[REDACTED]\…` before being stored in any report. Long opaque strings (hex digests, base64-like blobs, API key prefixes such as `sk-` or `ghp_`) are replaced with `[REDACTED_TOKEN]`. Hostnames in scan results are stored only as a SHA-256 digest.

## Your responsibility

Even with redaction, scan reports describe the configuration of your machine and should be treated as sensitive. Store them somewhere only you (or parties you trust) can read them. See `SECURITY.md`.
